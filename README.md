## 3. Qué hace
- Marca un punto del camino con categoría, descripción y hora.
- Muestra la lista filtrada por hora del día.
- Comparte un reporte por texto.

## 4. Cómo correrlo en tu máquina
git clone https://github.com/estelaamya/Ruta-Segura.git
Abrir con Android Studio, configurar la llave de API (ver .env.example) y ejecutar.

## 5. Tecnologías
Kotlin, Jetpack Compose, (almacenamiento usado), Gemini API (modelo usado).
